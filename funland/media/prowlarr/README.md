# Prowlarr

This directory contains the manifests for deploying [Prowlarr](https://prowlarr.com/), an indexer manager that syncs indexers to Radarr/Sonarr.

## Image

This deployment uses the `linuxserver/prowlarr` Docker image.

## Security context

Unlike this repo's other apps, this Deployment does **not** set `runAsNonRoot`/`runAsUser` or drop all Linux capabilities. `linuxserver.io` images use `s6-overlay`, which must start as root to prepare `/run` and then drops privileges to `PUID`/`PGID` itself; forcing a non-root UID or stripping `CAP_CHOWN`/`CAP_SETUID`/`CAP_SETGID` makes that startup fail outright (`s6-overlay-suexec: fatal: child failed with exit code 100`). `fsGroup: 568` is kept so PVC ownership still matches `PUID`/`PGID=568`.

## Access / SSO

Prowlarr is **not** exposed directly. `http-route.yaml` routes `prowlarr.batlab.io` (internal gateway only) to the shared `authentik-proxy` Service in the `authentik` namespace (see `funland/authentik/authentik-proxy/`), which reverse-proxies to this app's own Service only after Authentik authenticates the request. Access is restricted to the `media-admins` Authentik group.

Prowlarr trusts the outpost's authentication via `PROWLARR__AUTH__METHOD=External` so it doesn't also show its own login screen.

## Dependencies

- **Storage:** Longhorn PVC (`prowlarr-config`, 5Gi) for `/config`.
- **[External Secrets](https://external-secrets.io/):** Pulls the Prowlarr API key from 1Password.
- **[Authentik](https://goauthentik.io/):** SSO via the shared proxy outpost (see above).

## Secrets

`prowlarr-secret` ExternalSecret provides `api_key`, sourced from the `prowlarr` 1Password item's `api_key` property. This value is self-generated (not auto-generated by Prowlarr) and pre-seeded via the `PROWLARR__AUTH__APIKEY` env var so Recyclarr/other automation can reference the same key without a manual extraction step.

## Manual setup (no declarative equivalent)

In Prowlarr's UI, add Radarr and Sonarr under **Settings → Apps** using their API keys and in-cluster URLs (`http://radarr.media.svc.cluster.local:7878`, `http://sonarr.media.svc.cluster.local:8989`) — this integration lives in Prowlarr's own database, not a config file.
